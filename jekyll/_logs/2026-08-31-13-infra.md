- **빈 배열 허용부서가 문서를 통째로 숨기던 것을 고쳤다**
  allowed_departments='{}' 인 행은 IS NULL 도 ANY 도 못 넘어 아무에게도
  보이지 않는다. 자기 부서에도 안 보인다. 그런데 도메인은 정반대로
  정의한다 — Document.allowed_departments=() 는 전사 공개다.

  cardinality(...)=0 을 WHERE 에 넣었다. 어댑터가 () 를 NULL 로 정규화하는
  것은 계획에 이미 있으므로 이건 읽는 쪽의 이중 방어다. 데이터가 어떤
  경로로 들어왔든 도메인 정의대로 읽힌다.

  보안팀 전용 문서가 개발팀에게 0건인 것과 등급 필터가 그대로 도는 것을
  pgvector 컨테이너에서 확인했다.
